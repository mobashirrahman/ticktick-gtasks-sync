Privacy Policy — Ticktick-gcal sync

Last updated: 23 November 2026

Ticktick-gcal sync ("the application") is a personal, self-hosted tool operated by a single individual for their own use. It keeps that person's TickTick tasks mirrored into their own Google Tasks and Google Calendar. It is not offered to the public and has no other users.

What data is accessed

The application requests two Google OAuth scopes:

  • https://www.googleapis.com/auth/tasks — to read, create, update and complete tasks in the user's own Google Tasks lists.
  • https://www.googleapis.com/auth/calendar.events — to read, create, update and delete events on the user's own Google Calendar.

It also reads and writes task data through the user's own TickTick account via the TickTick Open API.

How data is used

Data is used solely to synchronize tasks and calendar blocks between the user's TickTick account and the same user's Google account. Task titles, notes, due dates, completion state and durations are transmitted between those services and are not used for any other purpose.

Storage

OAuth tokens and an identifier mapping between TickTick tasks and Google objects are stored on a server controlled by the operator, in access-restricted files. No task content is stored beyond what is needed for that mapping.

Sharing

No data is sold, shared, or transferred to any third party. The application communicates only with the TickTick and Google APIs, using the operator's own credentials.

Retention and deletion

Data lives in the operator's TickTick and Google accounts and is deleted when the operator deletes it in those services. Local tokens can be revoked at any time from the Google Account permissions page (myaccount.google.com/permissions) or by deleting the stored credentials file on the server.
